# 🐑 Bergerie — lots & rations

Mini-appli : barrières par aire, lots multi-aires, places au tapis, rations multi-aliments.

URL : https://vincentvaysset.github.io/Conges/bergerie/

Pense-bête :
- Appui long dans une aire = barrière à cet endroit (1 place ≈ 33 cm)
- Touche un morceau → choisir son lot, brebis et rations
- Touche une barrière → déplacer place par place ou supprimer
- Aliments : créer/renommer depuis l’écran Résumé

Données sauvegardées automatiquement (localStorage du navigateur).
