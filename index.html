Mes congés

Décompte CP en jours ouvrables : le décompte débute le premier jour où tu aurais dû travailler, le 1ᵉʳ samedi non travaillé n'est pas compté, les suivants le sont. Dimanches et jours fériés chômés jamais décomptés. Les CP sont pris en priorité sur le compteur N-1 (celui qui se solde au 31 mai).

Le décompte CP démarre le premier jour travaillé de la période posée.

1ᵉʳ samedi non décomptéSamedi non travaillé : le premier n'est pas compté, les suivants oui.

Jours fériés chômés non décomptésFériés tombant pendant les congés : jamais comptés.

Acquisition automatique +2,5 j / moisLes CP N s'accumulent tout seuls depuis le 1ᵉʳ juin, à chaque mois travaillé.

Règles CP (branche agricole / CUMA)
· Acquisition automatique : +2,5 jours ouvrables par mois travaillé sur le compteur CP N (soit 30 j / an). Si un mois n'est pas travaillé en entier, ajoute une écriture « CP acquis » négative sur le compteur N pour ajuster.
· Période de référence : du 1ᵉʳ juin au 31 mai (défaut en l'absence d'accord).
· Soldage : les CP N-1 doivent être posés avant le 31 mai suivant, sinon ils sont perdus (l'appli affiche un compte à rebours et décompte toujours en priorité sur les N-1).
· Tes données sont enregistrées dans ce navigateur, rien n'est envoyé sur internet.
